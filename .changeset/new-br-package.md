New `@cbrl/br` package: framework-free Brazilian domain utilities with zero runtime dependencies. It ships phone normalization, formatting and input masks plus WhatsApp link builders (`@cbrl/br/phone`), BRL formatters for reais and integer cents (`@cbrl/br/money`), CPF/CNPJ validation with check digits, normalization, formatting and masks (`@cbrl/br/tax-id`), and CEP normalization, formatting, masking and a BrasilAPI v2 lookup that returns a discriminated result instead of throwing (`@cbrl/br/postal-code`). Everything is also re-exported from the root.
